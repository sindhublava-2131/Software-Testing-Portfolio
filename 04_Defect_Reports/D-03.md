# Defect Report: D-03

## Body-less POST requests trigger unhandled TypeError resulting in HTTP 500 HTML stack dump

| Property | Value |
|---|---|
| **Defect ID** | `D-03` |
| **Module** | M1 Authentication |
| **Severity** | **High** |
| **Priority** | `P1` |
| **CWE Classification** | CWE-209: Generation of Error Message Containing Sensitive Information |
| **Triggering Test Cases** | `TC-AUTH-010`, `TC-EP-008` |
| **SUT Target Commit** | `ecd4de475fdf49d54153ffaa57d42b392161007a` |

### 1. Description
Under Express 5, when a client sends a POST request with empty or null body and Content-Type: application/json, object destructuring `const { email, password } = req.body` executed outside or before try/catch blocks triggers an uncaught `TypeError: Cannot destructure property 'email' of 'req.body' as it is undefined`. The default Express error handler then dumps a 500 HTML response with internal file paths.

### 2. Root Cause Analysis
Destructuring `req.body` directly without defaulting to an empty object (`req.body || {}`) in controller entry points.

### 3. Expected vs Actual Result
- **Expected**: HTTP 400 Bad Request JSON response: `{"message": "Email and password are required"}`.
- **Actual**: HTTP 500 Internal Server Error with HTML body and full V8 call stack.

### 4. Reproduction Steps
1. Navigate to test suite `05_Test_Automation/`.
2. Execute corresponding automated test: `npx vitest run --filter "TC-AUTH-010"`.
3. Observe honest test failure confirming defect behavior.

### 5. Recommended Remediation
Default destructuring: `const { email, password } = req.body || {};` and ensure comprehensive validation before accessing properties.
