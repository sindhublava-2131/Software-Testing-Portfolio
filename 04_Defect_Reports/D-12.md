# Defect Report: D-12

## ESLint 9 crash due to missing eslint.config.js flat configuration file

| Property | Value |
|---|---|
| **Defect ID** | `D-12` |
| **Module** | M7 Tooling |
| **Severity** | **Medium** |
| **Priority** | `P3` |
| **CWE Classification** | CWE-1068: Inconsistency Between Implementation and Documented Design |
| **Triggering Test Cases** | `TC-BL-001` |
| **SUT Target Commit** | `ecd4de475fdf49d54153ffaa57d42b392161007a` |

### 1. Description
The repository includes ESLint 9.x in `client/package.json` with an outdated `.eslintrc.cjs` configuration file. Running `npm run lint` crashes immediately with `ESLint: 9.27.0. Could not find a config file in /client... ESLint couldn't find an eslint.config.(js|mjs|cjs) file`.

### 2. Root Cause Analysis
Failure to migrate to ESLint 9 Flat Config system.

### 3. Expected vs Actual Result
- **Expected**: `npm run lint` executes successfully and reports linting findings.
- **Actual**: Fatal process termination with code 2.

### 4. Reproduction Steps
1. Navigate to test suite `05_Test_Automation/`.
2. Execute corresponding automated test: `npx vitest run --filter "TC-BL-001"`.
3. Observe honest test failure confirming defect behavior.

### 5. Recommended Remediation
Migrate configuration to `eslint.config.js` or set `ESLINT_USE_FLAT_CONFIG=false`.
