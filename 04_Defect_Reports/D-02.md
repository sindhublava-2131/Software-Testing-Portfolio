# Defect Report: D-02

## Current highest bidder permitted to outbid themselves repeatedly

| Property | Value |
|---|---|
| **Defect ID** | `D-02` |
| **Module** | M3 Live Bidding |
| **Severity** | **High** |
| **Priority** | `P2` |
| **CWE Classification** | CWE-840: Business Logic Errors |
| **Triggering Test Cases** | `TC-BID-021`, `TC-DT-004` |
| **SUT Target Commit** | `ecd4de475fdf49d54153ffaa57d42b392161007a` |

### 1. Description
The bidding validation checks that the seller does not bid on their own auction (`product.seller.toString() === user`), but never checks whether the highest bidder is currently the calling user. A bidder can inflate the auction price by outbidding themselves consecutively.

### 2. Root Cause Analysis
Omission of check against highest existing bid: `if (product.bids.length > 0 && product.bids[product.bids.length - 1].bidder.toString() === user) return res.status(400)...` in `auction.controller.js` and `auction.handler.js`.

### 3. Expected vs Actual Result
- **Expected**: HTTP 400 Bad Request with message "You are already the highest bidder".
- **Actual**: HTTP 200 OK — duplicate bid recorded and price increased.

### 4. Reproduction Steps
1. Navigate to test suite `05_Test_Automation/`.
2. Execute corresponding automated test: `npx vitest run --filter "TC-BID-021"`.
3. Observe honest test failure confirming defect behavior.

### 5. Recommended Remediation
Verify the last bidder in `product.bids` array and reject if matching `req.user.id`.
