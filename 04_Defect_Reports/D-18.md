# Defect Report: D-18

## Production Vite bundle generated as single monolithic 595.17 kB chunk exceeding chunk threshold

| Property | Value |
|---|---|
| **Defect ID** | `D-18` |
| **Module** | M7 Frontend Architecture |
| **Severity** | **Low** |
| **Priority** | `P4` |
| **CWE Classification** | CWE-400: Uncontrolled Resource Consumption |
| **Triggering Test Cases** | `TC-BL-002` |
| **SUT Target Commit** | `ecd4de475fdf49d54153ffaa57d42b392161007a` |

### 1. Description
Running `vite build` produces a single JavaScript bundle of 595.17 kB, triggering Vite's build warning: `(!) Some chunks are larger than 500 kB after minification`. No manual chunk splitting or lazy loading (`React.lazy`) is configured for routes.

### 2. Root Cause Analysis
Absence of `manualChunks` in `vite.config.js` and lack of dynamic route imports.

### 3. Expected vs Actual Result
- **Expected**: Code-split bundles with vendor chunks < 500 kB.
- **Actual**: Single monolithic 595.17 kB chunk loaded on initial page visit.

### 4. Reproduction Steps
1. Navigate to test suite `05_Test_Automation/`.
2. Execute corresponding automated test: `npx vitest run --filter "TC-BL-002"`.
3. Observe honest test failure confirming defect behavior.

### 5. Recommended Remediation
Implement route-level dynamic imports `React.lazy()` and configure `build.rollupOptions.output.manualChunks`.
