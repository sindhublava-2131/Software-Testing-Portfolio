# Defect Report: D-15

## Spoofed X-Forwarded-For IP address unconditionally trusted for security audit logging

| Property | Value |
|---|---|
| **Defect ID** | `D-15` |
| **Module** | M4 Profile & Auditing |
| **Severity** | **Medium** |
| **Priority** | `P2` |
| **CWE Classification** | CWE-290: Authentication Bypass by Spoofing |
| **Triggering Test Cases** | `TC-USR-013` |
| **SUT Target Commit** | `ecd4de475fdf49d54153ffaa57d42b392161007a` |

### 1. Description
In `auth.controller.js:34`, user login audit logs capture IP via `const ip = req.headers["x-forwarded-for"] || req.socket.remoteAddress`. An attacker can supply an arbitrary header `X-Forwarded-For: 8.8.8.8` to poison security login history and forensic records.

### 2. Root Cause Analysis
Direct reading of un-sanitized client request header without proxy trust configuration.

### 3. Expected vs Actual Result
- **Expected**: Validated IP address with `app.set("trust proxy", ...)` or remote socket IP.
- **Actual**: Arbitrary client-supplied spoofed IP saved to database `Login` record.

### 4. Reproduction Steps
1. Navigate to test suite `05_Test_Automation/`.
2. Execute corresponding automated test: `npx vitest run --filter "TC-USR-013"`.
3. Observe honest test failure confirming defect behavior.

### 5. Recommended Remediation
Configure Express proxy trust policy and parse only leftmost IP from trusted reverse proxy.
