# Defect Report: D-16

## WebSocket bid with null or missing amount returns early without emitting auction:error

| Property | Value |
|---|---|
| **Defect ID** | `D-16` |
| **Module** | M3 Live Bidding |
| **Severity** | **Medium** |
| **Priority** | `P2` |
| **CWE Classification** | CWE-754: Improper Check for Unusual or Exceptional Conditions |
| **Triggering Test Cases** | `TC-SOC-012` |
| **SUT Target Commit** | `ecd4de475fdf49d54153ffaa57d42b392161007a` |

### 1. Description
In `socket/auction.handler.js:42`, the handler executes: `if (!auctionId || bidAmount == null) return;`. The function returns silently without emitting any error event back to the socket. The frontend client hangs indefinitely awaiting confirmation.

### 2. Root Cause Analysis
Early return without emitting `auction:error` event.

### 3. Expected vs Actual Result
- **Expected**: Socket client receives `auction:error` with message "Invalid bid amount".
- **Actual**: No event emitted; client hangs awaiting callback or response.

### 4. Reproduction Steps
1. Navigate to test suite `05_Test_Automation/`.
2. Execute corresponding automated test: `npx vitest run --filter "TC-SOC-012"`.
3. Observe honest test failure confirming defect behavior.

### 5. Recommended Remediation
Replace silent return with `socket.emit("auction:error", { message: "Invalid bid amount" }); return;`.
