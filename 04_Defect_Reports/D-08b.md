# Defect Report: D-08b

## Absence of HTTP security headers and sensitive technology disclosure (X-Powered-By)

| Property | Value |
|---|---|
| **Defect ID** | `D-08b` |
| **Module** | M7 Architecture |
| **Severity** | **Medium** |
| **Priority** | `P2` |
| **CWE Classification** | CWE-200: Exposure of Sensitive Information to an Unauthorized Actor |
| **Triggering Test Cases** | `TC-SEC-009` |
| **SUT Target Commit** | `ecd4de475fdf49d54153ffaa57d42b392161007a` |

### 1. Description
The Express application does not utilize `helmet`. Every response leaks `X-Powered-By: Express` and omits critical defensive headers including `X-Frame-Options` (clickjacking protection), `Content-Security-Policy`, `X-Content-Type-Options: nosniff`, and `Strict-Transport-Security`.

### 2. Root Cause Analysis
Missing `app.use(helmet())` and `app.disable("x-powered-by")`.

### 3. Expected vs Actual Result
- **Expected**: Strict security headers present; `X-Powered-By` omitted.
- **Actual**: `X-Powered-By: Express` present in every HTTP header; security headers missing.

### 4. Reproduction Steps
1. Navigate to test suite `05_Test_Automation/`.
2. Execute corresponding automated test: `npx vitest run --filter "TC-SEC-009"`.
3. Observe honest test failure confirming defect behavior.

### 5. Recommended Remediation
Import and invoke `helmet()` middleware in `app.js`.
